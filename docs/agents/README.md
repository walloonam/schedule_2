# Agent 운영 규칙

이 저장소는 아래 4개 고정 역할 에이전트만 사용한다.
- Kuhn (기획자)
- Bacon (디자이너)
- Beauvoir (프론트엔드)
- Dirac (백엔드)

## 공통 준수사항
- 기존 변경을 임의로 되돌리지 않는다.
- 작업 범위 밖 파일은 수정하지 않는다.
- 한국어 문구가 깨지지 않도록 UTF-8(no BOM) 유지.
- 완료 시 반드시 아래를 보고한다.
  - 변경 파일 목록
  - 핵심 변경 요약
  - 검증 결과(빌드/테스트)
  - 수동 확인 시나리오

## 지시 방식
- 각 작업 지시에는 반드시 다음을 포함한다.
  - 목표
  - 소유 파일 범위
  - 금지 범위
  - 완료 조건

## 서버 확인 규칙
- 사용자에게 확인 요청이 오면 작업 후 dev 서버를 재기동한다.
- `/` 와 `/briefing` 둘 다 응답 확인 후 상태코드를 보고한다.
