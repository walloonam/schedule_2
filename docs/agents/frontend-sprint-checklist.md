# 프론트 스프린트 검증 체크리스트

서버 엔지니어 Shannon 기준으로, 요청이 오면 아래 순서대로 바로 검증한다.

## 1) Dev Server
- `npm run dev -- --port 3000`
- 확인: 서버가 `Ready` 상태까지 올라오고, `0.0.0.0:3000` 또는 `127.0.0.1:3000`에 리슨 중인지 확인

## 2) 200 응답
- `curl -I http://127.0.0.1:3000/`
- `curl -I http://127.0.0.1:3000/briefing`
- 확인: 둘 다 `HTTP/1.1 200 OK`

## 3) Lint
- `npm run lint`
- 확인: 에러 없이 종료

## 4) Build
- `npm run build`
- 확인: 타입 오류, CSS 오류, 라우트 오류 없이 종료

## 5) UI Smoke Test
- `/`에서 캘린더 첫 화면이 정상 렌더되는지 확인
- `/briefing`에서 브리핑 카드와 요약이 정상 렌더되는지 확인
- 확인: 빈 화면, 런타임 에러, 주요 버튼 미응답이 없어야 함

## 보고 기준
- 실행한 명령
- 포트 점유 상태
- `lint/build` 성공 여부
- `/`, `/briefing`의 200 응답 결과
- UI smoke test에서 발견한 문제
